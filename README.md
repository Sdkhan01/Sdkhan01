## Production Systems

### AI Front Desk for Clinics
Patients chat on the clinic website or WhatsApp. The agent answers from the clinic's
own documents, checks the doctor's live schedule, books the appointment, and emails
confirmations plus 24h and 2h reminders. Several clinics run on one backend with fully
isolated data.

> **Built:** multi-tenant architecture, live slot availability, structured booking flow,
> human takeover with typing indicators, role based staff accounts (admin / agent / viewer)
>
> `FastAPI` `LangGraph` `PostgreSQL` `Next.js` `Telegram API` `WhatsApp Cloud API`

### AI Support Desk
RAG answers grounded in a company's own documents, with a confidence score on every
reply. Escalates to a human automatically when it is unsure, and an agent can take over
mid conversation with the customer seeing them join.

> **Built:** RAG retrieval over pgvector, confidence scoring, escalation rules,
> live agent handoff, conversation analytics, embeddable one line widget
>
> `FastAPI` `LangChain` `OpenAI` `pgvector` `Next.js` `SSE streaming`
>
> **[Try it live, no signup required](https://eligentai-support.vercel.app)**
